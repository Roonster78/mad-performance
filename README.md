# MAD Performance Karting – Team-Dashboard

Zwei Browser-Apps ohne Build-Schritt, als GitHub Pages veröffentlicht:

- `dashboard/` – **MAD Boxenmauer**: Uhr, Countdown, Regenradar, Wetter, Tageszeitplan mit Erinnerungen, Livetiming (Apex), Livestream, Starterfeld, Checkliste.
- `webapp/` – **MAD Telemetrie**: ALFANO-7-Import (`.alf2`), Runden-Overlay, Kurven, Strecke, Sektoren, ADA-Pro-Funktionen.

Online: https://roonster78.github.io/mad-performance/
